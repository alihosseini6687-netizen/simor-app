- URL منوی BotFather را تغییر ندهید.
- این پیش‌نمایش از ذخیره محلی جداگانه استفاده می‌کند و همگام‌سازی CloudStorage تلگرام در آن غیرفعال است.

- اطلاعات سکه و ژتون در نسخه فعلی هنوز مرجع امن سروری ندارند.
