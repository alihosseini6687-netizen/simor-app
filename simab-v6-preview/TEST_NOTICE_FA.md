# SIMAB V6 — نسخه آزمایشی مخصوص انتشار آنلاین

این بسته برای بارگذاری در GitHub Pages ساخته شده و شامل پوشه `simab-v6-preview` است. **فقط همین پوشه را** پس از استخراج به مخزن منتقل کن؛ فایل ZIP را مستقیماً آپلود نکن.

نشانی پیش‌نمایش بعد از انتشار در GitHub Pages:
https://alihosseini6687-netizen.github.io/simor-app/simab-v6-preview/

## نکات امنیتی
- نسخه اصلی در آدرس `https://alihosseini6687-netizen.github.io/simor-app/` بدون تغییر می‌ماند.
- `localStorage` این پیش‌نمایش با پیشوند اختصاصی جدا می‌شود تا حساب و سکه نسخه اصلی تغییر نکند.
- `Telegram CloudStorage` به طور عمدی در نسخه آزمایشی خاموش است. این صفحه برای تست ظاهر، لینک‌ها، کنترل‌ها و بازی مهمان طراحی شده، **نه تست احراز هویت واقعی تلگرام یا پنل مدیریت**.
- در مینی‌اپ اصلی BotFather آدرس Menu Button را تغییر نده.
- سکه‌های نمایش داده‌شده در پیش‌نمایش واقعی/سروری نیستند. امکانات پول واقعی فعال نیست.

## بارگذاری
۱) ZIP را با Extract All از حالت فشرده خارج کن.
۲) مخزن GitHub سیماب را باز کن > Add file > Upload files.
۳) **پوشه `simab-v6-preview`** را از داخل ویندوز به کادر Upload بکش و رها کن. ساختار پوشه باید حفظ شود.
۴) حتماً مسیرها را کنترل کن: `simab-v6-preview/index.html` و `simab-v6-preview/assets/v3/hero.webp`.
۵) یک commit با عنوان `test: add isolated V6 preview` ثبت کن.
۶) پس از اتمام GitHub Pages Actions، لینک پیش‌نمایش بالا را باز کن.

اگر GitHub اجازه بارگذاری پوشه نداد یا خطا داد، اسکرین‌شات بفرست تا روش GitHub Desktop را انجام بدهیم.
