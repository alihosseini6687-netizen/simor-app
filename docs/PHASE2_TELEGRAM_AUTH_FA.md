# فاز ۲.۲ سیماب — پیش‌نویس ورود امن تلگرام

ربات: @SimorApp_bot

این کد فقط در شاخه توسعه قرار دارد. به نسخه اصلی بازی وصل نشده است. توکن ربات را هرگز به GitHub یا چت ارسال نکن.

۱. قبل از اجرا، نتیجه RLS و مجوزهای چهار جدول را در Supabase بررسی کن (true و 0).

۲. آدرس HTTPS مینی‌اپ را در BotFather بررسی کن ولی فعلاً تغییر نده.

۳. فایل SQL داخل supabase/migrations را فقط پس از تأیید مرحله ۱ در SQL Editor اجرا کن.

۴. secret با نام SIMAB_TELEGRAM_BOT_TOKEN باید فقط در تنظیمات محرمانه Edge Functions وارد شود.

۵. اجرای Edge Function باید verify_jwt=false داشته باشد چون تأیید هویت آن با امضای Telegram initData در خود تابع انجام می‌شود. Endpoint را قبل از تست امنیتی عمومی نکن.

۶. این عملیات حساب تلگرام را ایجاد می‌کند و کیف پول صفر افتتاح می‌کند؛ موجودی قبلی در مرورگر دست‌نخورده باقی می‌ماند. هیچ انتقال سکه انجام نمی‌شود.

۷. ورود مستقل اندروید و آیفون و مدیریت نشست‌ها هنوز پیاده‌سازی نشده‌اند.
