# SIMAB — اتصال کانال رسمی و اصلاح مأموریت‌ها

کانال رسمی معرفی‌شده: https://t.me/SimorApp (نام عمومی `@SimorApp`).
ربات اصلی: `@SimorApp_bot` — این دو آدرس متفاوت هستند.

## اصلاح‌شده در GitHub
- فقط آدرس دقیق همین کانال می‌تواند مأموریت عضویت قابل‌پاداش باشد؛ لینک بات یا کانال دیگر پاداش نمی‌گیرد.
- وضعیت مدیر بودن خود ربات در کانال با Telegram Bot API بررسی می‌شود؛ اگر ربات مدیر نباشد، دریافت جایزه و ارسال پیام **مسدود** می‌ماند.
- API وضعیت اتصال دلیل غیرفعال بودن را به مدیر نشان می‌دهد.
- لینک پیش‌فرض صفحه مأموریت‌ها به کانال اصلاح و وعده ۲۰ سکه بدون تأیید حذف شد.
- اگر مأموریت کانال در لیست مرکزی باشد، کارت تکراری قدیمی مخفی می‌شود.
- موجودی جایزه تأییدشده مستقل از فعال/غیرفعال بودن پرداخت‌های تازه قابل دیدن است.
- پنل مدیریت دکمه آماده‌سازی مأموریت کانال رسمی با پاداش آزمایشی ۱ سکه دارد؛ انتشار نیازمند کلیک مدیر است.
- مقادیر منفی/خراب CloudStorage در پنل مدیریت دیگر بی‌بررسی پذیرفته نمی‌شوند. شارژ محلی آزمایشی به جای شارژ واقعی معرفی می‌شود.
- SQL دفتر پاداش به گفته کاربر قبلاً با موفقیت اجرا شده و **نیازی به اجرای مجدد آن نیست**.

## مرحله کوتاه باقی‌مانده
۱. وارد کانال `@SimorApp` در تلگرام شو و `@SimorApp_bot` را به‌عنوان **Administrator** اضافه کن؛ دسترسی `Post Messages` برای ارسال پیام لازم است. ربات باید بتواند وضعیت اعضا را با `getChatMember` بررسی کند.

۲. پس از مدیر شدن ربات، از GitHub Actions ابزار «Deploy SIMAB central quests to Supabase» را **یک بار از شاخه main** اجرا کن. نیازی به تنظیم `SIMAB_TELEGRAM_CHANNEL` یا SQL جدید نیست؛ شناسه کانال عمومی در کد سمت سرور تعیین شده است. توکن ربات همچنان فقط در Supabase Secrets است.

۳. پس از موفق شدن انتشار، در مدیریت دکمه «بررسی اتصال و حساب مدیریت» را بزن. انتظار: ربات، امضا، مدیر و مدیر بودن ربات در کانال همگی تأیید شوند.

۴. اگر هنوز مأموریت مرکزی عضویت کانال وجود ندارد، دکمه «آماده‌سازی مأموریت کانال رسمی» را بزن و پس از بازبینی **پاداش ۱ سکه** آن را منتشر کن؛ سپس داخل تلگرام با حساب عضو و غیرعضو تست کن. هیچ سکه‌ای از کیف پول قدیمی بازی به این دفتر وارد نمی‌شود.

## نکات امنیتی حل‌نشده
- نتیجه و تسویه پوکر، تخته‌نرد، اسلات و دیگر بازی‌ها هنوز در کلاینت است؛ این بسته آن‌ها را به کیف پول سروری منتقل نکرد.
- نرخ درخواست و کنترل ضدتقلب، چنددستگاهی و مهاجرت موجودی قبلی هنوز نیاز به طراحی و اجرا دارند.
- برای تست امنیت، کاربر عضو باید حداکثر یک بار جایزه بگیرد؛ غیرعضو نباید جایزه بگیرد. در صورت خطای سرور، هیچ واریزی انجام نشود.
- این تست‌ها تضمین عملکرد واقعی تلگرام نیستند؛ پس از Deploy یک تست واقعی لازم است.
