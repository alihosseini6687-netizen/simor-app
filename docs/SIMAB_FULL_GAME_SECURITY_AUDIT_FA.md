# SIMAB — گزارش امنیت و پایداری تمام بازی‌ها (بسته اصلاحی بعد از SQL)

تاریخ: اکتبر ۲۰۲۶

## نتیجه SQL
تصویر صاحب پروژه: اجرای `20261012_verified_quest_rewards.sql` با `Success. No rows returned` تمام شده است. این تأیید موفقیت دستور SQL است؛ **هنوز دریافت واقعی جایزه یا استقرار Edge Function جدید را ثابت نمی‌کند.** نیازی به اجرای دوباره همان SQL نیست.

## اصلاحات انجام‌شده در این بسته
- ورود بدون اطلاعات تلگرام در پوکر، تخته‌نرد، اسلات و صرافی دیگر به حساب ثابت مدیر `702007470` نسبت داده نمی‌شود؛ از `guest` استفاده می‌شود.
- کلید قدیمی اشتراکی `user_balance` دیگر منبع یا مقصد موجودی سکه در صرافی، تخته‌نرد و گردونه Tap نیست.
- کارت هدیه اکنون فقط اعتبار نمایشی مستقل `simab_cards_demo_<user>` دارد؛ خرید آن سکه اصلی بازی را کم/زیاد نمی‌کند.
- روی ۱۱ صفحه، تابع مشترک و سبک `assets/js/simab-legacy-guard.js` برای رد موجودی منفی، Infinity، NaN، و ژتون‌های نامعتبر نصب شده است.
- واردکردن CloudStorage در خانه، صرافی و تخته‌نرد از نظر سکه، تعداد ژتون‌ها و مقادیر موجودی تفکیکی کنترل می‌شود.
- مسیرهای داخلی صفحات اصلی و کدهای JavaScript توسط GitHub Actions بررسی شدند.
- هیچ تغییر خودکار/تخریبی روی موجودی ذخیره‌شده معتبر انجام نمی‌شود.

**هشدار:** این اصلاحات کیفیت ذخیره محلی را افزایش می‌دهند اما امنیت مالی یا ضدتقلب سروری ایجاد نمی‌کنند. localStorage و CloudStorage همچنان توسط خودِ کلاینت نوشته می‌شوند.

## اولویت امنیتی برای فاز بعد
1. **P0**: جدول و RPC کیف پول یکپارچه سکه/ژتون و دفتر تراکنش تمام بازی‌ها.
2. **P0**: تصمیم درباره اعتبار و مهاجرت موجودی قدیمی؛ اعتبار ذخیره محلی نباید کورکورانه به حساب معتبر تبدیل شود.
3. **P0**: تصادفی‌بودن و نتیجه بازی‌ها در سرور و محاسبه یک‌باره برد/باخت.
4. **P1**: محدودسازی درخواست، ثبت وقایع ضدتقلب، بررسی چند دستگاه و نشست‌ها.
5. **P1**: تنظیمات مدیریت متمرکز، ارسال کانال و رویدادها.
6. **P2**: زیباسازی و نسخه‌های نصب Android/iOS، با تست موبایل واقعی.

## ادامه فعال‌سازی مأموریت با کمترین کار دستی
- مرحله SQL دفتر پاداش **انجام‌شده** گزارش شده؛ آن را تکرار نکن.
- برای دریافت جایزه عضویت واقعی، یک **کانال عمومی تلگرام** لازم است؛ لینک `@SimorApp_bot` مربوط به بات است و عضویت در کانال محسوب نمی‌شود.
- ربات باید در همان کانال ادمین با مجوز لازم برای `getChatMember` باشد.
- Secret `SIMAB_TELEGRAM_CHANNEL` با شناسه عمومی واقعی کانال (مثل `@YourChannel`) در Supabase ثبت شود؛ توکن بات را نمایش نده.
- سپس **یک‌بار** GitHub Actions «Deploy SIMAB central quests to Supabase» از main اجرا شود.
- پس از آن تست: عضو کانال ۱ بار جایزه، بار دوم ۰ جایزه جدید، غیرعضو 403، داده امضاشده جعلی 401، موجودی اصلی قدیمی دست‌نخورده.

## تست
`node --test tests/*.test.mjs`

سبزبودن تست‌ها، **جایگزین تست تعاملی مرورگر تلگرام و صحت دیتابیس اصلی نیست**. تا تکمیل کیف پول سروری، سکه‌های بازی فقط اعتبار آزمایشی‌اند و نباید به‌عنوان دارایی واقعی یا قابل برداشت نمایش داده شوند.
