# SIMAB — امنیت و پاداش مأموریت‌ها (مرحله ۲)

**این بسته بدون تصمیم‌گیری درباره اقتصاد کلی بازی نوشته شده است.** هر جایزه واقعی فقط در دفتر مستقل پاداش تأییدشده سرور ثبت می‌شود؛ سکه‌های فعلی مرورگر/Telegram CloudStorage انتقال یا تغییر داده نمی‌شوند.

## اصلاح‌شده در کد این بسته
- شناسایی واقعی کاربر فقط با Telegram initData امضاشده، نه شناسه ارسالی مرورگر
- تأیید عضویت فقط از طریق Telegram Bot API / getChatMember
- تطبیق نام کانال مأموریت با Secret کانال مشخص، نه هر لینک t.me
- ردکردن جایزه برای پیوند ربات، گوگل یا اینستاگرام؛ بازدید و تایمر دلیل دریافت نیست
- قفل یکتای دیتابیس روی (کاربر، مأموریت) و ثبت اتمیک یک‌باره سکه تأییدشده
- RLS و عدم دسترسی anon و authenticated به جدول‌ها یا تابع واریز
- نمایش موجودی پاداش امن به صورت جدا از سکه‌های قدیمی بازی
- دکمه دریافت با توقف کلیک تکراری، نشان‌دادن جایزه قبلی و پیام خطای واقعی

## ترتیب فعال‌سازی با کمترین خطر
۱. **SQL**: در پروژه Supabase `simab-game` فایل `supabase/migrations/20261012_verified_quest_rewards.sql` را در SQL Editor اجرا کن. جداول قبلی و سکه‌های بازیکنان را تغییر نمی‌دهد.

۲. **کانال**: فقط اگر یک کانال عمومی واقعی داری، ربات `@SimorApp_bot` را ادمین همان کانال کن و در Supabase > Edge Functions > Secrets مقدار `SIMAB_TELEGRAM_CHANNEL` را برابر **@نام_عمومی_کانال** ثبت کن. مقدار `@SimorApp_bot` درست نیست، چون این ربات است نه کانال. توکن بات را نمایش نده.

۳. **انتشار**: از GitHub Actions ابزار `Deploy SIMAB central quests to Supabase` را روی main اجرا کن. این مرحله فقط Edge Function موجود را منتشر می‌کند.

۴. **آزمایش امن**: مأموریت عضویت با لینک دقیق همان کانال و پاداش **۱ سکه** بساز؛ کاربر عضو جایزه ۱ بار بگیرد، کلیک تکراری دوباره جایزه ندهد، غیرعضو جایزه نگیرد، حساب جعلی 401 بگیرد. صفحه مأموریت باید موجودی تأییدشده را جدا از موجودی اصلی نشان دهد.

## قواعد امنیتی
- مقدار Secretها، توکن‌ها یا initData را داخل GitHub، عکس یا چت قرار نده.
- **هیچ انتقال خودکار سکه قدیمی** به موجودی تأییدشده در این بسته وجود ندارد.
- تست‌های GitHub به معنای تست دیتابیس و تأیید واقعی عضویت نیستند؛ تست حضوری یک بار لازم است.
- قبل از استقرار SQL و تنظیم کانال، «سکه پیشنهادی» به معنی قابل دریافت نیست.
- مسیر خرید/فروش/انتقال سکه و تبدیل ژتون باید تا پیاده‌سازی دفتر سروری امن بسته بماند.

برای تست خودکار: `node --test tests/*.test.mjs`
