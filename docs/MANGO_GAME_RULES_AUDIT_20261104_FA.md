# Mango Game — ممیزی قوانین بازی‌ها (۴ نوامبر ۲۰۲۶)
**این سند فقط مقایسهٔ قواعد و پیشنهاد است؛ هیچ قانون موتور بازی یا جایزه‌ای به‌واسطهٔ این سند عوض نشده است.**
منابع رسمی/معتبر زیر به همراه موتورهای `games.ts`، `table-games.ts`، `party-games.ts`، `hokm-variants.ts` و قواعد تمرینی موجود مقایسه شده‌اند. تست دو گوشی، پرداخت واقعی و بررسی حقوقی منطقه‌ای جداگانه انجام می‌شود.

## پیگیری قبل از تغییر قوانین
۱. **تخته‌نرد:** داو و ضریب مارس/بک‌گامون را می‌خواهیم یا نسخهٔ فعلی ساده باقی بماند؟
۲. **منچ:** قانون ویژهٔ سه ۶ و ستاره‌ها حفظ شود یا مطابق نسخهٔ کلاسیک یکسان شود؟
۳. **هفت‌خبیث:** نسخهٔ اعلام‌شدهٔ کارت ۲ با انتقال کارت به عنوان قانون ثابت Mango ثبت شود یا گزینهٔ میز داشته باشد؟
۴. **بلک‌جک دوستانه:** نام «۲۱ رقابتی» حفظ شود تا با بلک‌جک استاندارد اشتباه نشود؟
۵. **ماروپله:** تاس به‌جای گردونه یک قاعدهٔ آشکار نسخهٔ بازی است.
